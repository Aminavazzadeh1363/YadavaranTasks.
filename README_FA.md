# یادآوران | YadavaranTasks

نسخه اولیه اندروید برای ثبت کارها و دریافت یادآوری.

## امکانات فعلی
- رابط فارسی و راست‌چین
- ورود تاریخ شمسی به شکل `۱۴۰۵/۰۸/۱۵` یا `1405/08/15`
- تعیین ساعت یادآوری
- اعلان برای هر وظیفه
- تکرار ماهانه
- انجام‌شده / بازگردانی / حذف
- ذخیره محلی روی گوشی
- بازتنظیم یادآورها پس از روشن شدن دوباره گوشی

## ساخت APK با GitHub Actions
1. فایل ZIP را از حالت فشرده خارج کنید.
2. محتویات پوشه را در ریشه مخزن `YadavaranTasks` بارگذاری کنید.
3. در GitHub وارد بخش Actions شوید.
4. گزینه `Build Android APK` را اجرا کنید.
5. پس از موفقیت، از بخش Artifacts فایل `YadavaranTasks-debug-apk` را دریافت کنید.
6. فایل `app-debug.apk` را روی گوشی نصب کنید.

## نکته درباره آلارم
در اندروید 13 به بعد، اجازه اعلان‌ها را هنگام اجرای اول برنامه فعال کنید. برای اطمینان از رسیدن اعلان‌ها، محدودیت باتری برنامه را نیز در تنظیمات گوشی روی حالت بدون محدودیت قرار دهید.
این نسخه از آلارم زمان‌بندی‌شده قابل‌اعتمادتر از یک اعلان ساده استفاده می‌کند، اما زمان دقیق اجرا ممکن است با سیاست صرفه‌جویی باتری سازنده گوشی کمی جابه‌جا شود.
